# Практическая работа №4 по PHP

Автозагрузка, абстрактные классы и свойства.

## Запуск

PHP 8.1 или новее. Из корня репозитория:

- `php task1/index.php` — простая автозагрузка.
- `php task2/index.php` — автозагрузка PSR-4.
- `php task3/index.php` — фигуры.
- `php task4/index.php` — сотрудники.
- `php project/index.php` — каталог товаров.

## Контрольные вопросы

1. **Когда вызывается автозагрузчик?** При обращении к ещё не загруженному классу PHP вызывает зарегистрированные автозагрузчики. Если класс не найден ни одним из них, возникает ошибка `Error` (Class not found).
2. **Преимущество spl_autoload_register() перед __autoload()?** Можно зарегистрировать несколько автозагрузчиков, которые будут вызываться по очереди. Функция __autoload() позволяла использовать только один автозагрузчик и удалена в PHP 8.0.
3. **Отличие абстрактного класса от интерфейса.** Абстрактный класс может хранить состояние, конструктор и реализацию общих методов. Интерфейс задаёт контракт без реализации методов. Класс может наследовать только один класс, но реализовать несколько интерфейсов. Абстрактный класс выбирают для общего состояния и поведения, интерфейс — для общего контракта разных классов.
4. **Можно ли создать объект абстрактного класса или объявить абстрактное свойство?** Создать объект абстрактного класса напрямую нельзя. В PHP 8.1–8.3 абстрактные свойства не поддерживаются, поэтому в рамках задания используют абстрактные методы или конструктор. Начиная с PHP 8.4 абстрактные свойства поддерживаются через хуки свойств ([документация PHP](https://www.php.net/manual/en/language.oop5.abstract.php)).
5. **Отличие static-свойства от обычного.** Обычное свойство хранится в каждом объекте отдельно, статическое принадлежит классу и является общим для его объектов. Внутри класса используют `self::$count`, снаружи — `ИмяКласса::$count`, если свойство публичное. Для закрытого свойства можно использовать публичный статический метод.
6. **Что делает readonly?** Разрешает инициализировать типизированное свойство один раз, после чего нельзя присвоить ему новое значение или изменить его напрямую. Если в свойстве хранится объект, его внутреннее состояние может изменяться. В данной работе readonly-свойство задаётся в конструкторе.
